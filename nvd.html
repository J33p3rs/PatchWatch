What the number means

Patch Watch queries the NVD CVE API 2.0 for each calendar month and counts records returned by publication date with rejected CVEs excluded.

This is a global vulnerability publication measure, not a vendor patch count. NVD is deliberately isolated from the vendor/platform All calculation because the same CVEs can already appear in Microsoft, Fortinet, Apple, Chrome and future platform feeds.

Future NVD-specific enrichment can add severity, CVSS, CISA KEV overlap and CWE trends without changing the vendor dashboard's aggregation model.
