What the number means

Patch Watch queries the NVD CVE API 2.0 for each calendar month and counts records returned by publication date with rejected CVEs excluded.

This is a global vulnerability publication measure, not a vendor patch count. NVD is deliberately isolated from the vendor/platform All calculation because the same CVEs can already appear in Microsoft, Fortinet, Apple, Chrome, Firefox, Linux and future platform/project feeds.

The vendor/project-vs-global chart compares normalised rolling trends, not raw totals. It is intended to answer questions such as whether one tracked series is increasing faster or slower than the broader NVD publication trend.
